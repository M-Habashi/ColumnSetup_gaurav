Figures 1–3 are diagrams rather than MATLAB-generated plots; they remain embedded in the manuscript. The `matlab/` folder contains all ten MATLAB source files found in the publication figure-source directory, preserved unchanged, including older alternatives. The active equivalents for `margins`, `margins_evolve`, `ncf`, and `Figure_10_weighting_factors` are in `simulation/scripted/`; run those there, since these functions resolve model inputs relative to their own location. Do not add the archived `figures/matlab` folder ahead of the active scripted folder for these commands.

For the active scripted plots, set MATLAB's current folder to `main/paper1/simulation/scripted`, open the chosen file, then call `margins(false)`, `margins_evolve(false)`, or `ncf`. The included saved controller configuration supplies the model settings. `false` suppresses export where supported; other scripts export to their configured result/source folder.

For independent legacy/publication scripts such as the heatmap or Bode/Nyquist illustration, add `main/paper1/simulation/helper` to the MATLAB path and load `main/paper1/simulation/Building cases/Case_1.mat` when requested by the script. Open the figure script and set its containing folder as current before running. Workspace-dependent scripts, including `theoritical_alpha.m`, need the legacy simulation's controller/specimen variables first; the direct numerical alternative is `simulation/scripted/theoretical.m`.

The saved four-case batch is under `simulation/Results/paper_rerun_20260902_121057*`. Pass a specific saved MAT path to a plot function when supported; its source header documents the arguments. These historical results preserve their original filenames, which may differ from the default `case_XX_*` glob used by convenience replot commands. Running `scripted_run_all_paper_cases` produces a new complete batch. No plot or simulation was executed during packaging.
