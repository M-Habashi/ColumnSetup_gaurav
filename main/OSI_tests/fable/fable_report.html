Verdict. On healthy data the previous indicator read a near-constant ≈0.3 (its residual branch is statistically biased low) so its authority collapsed to the 0.08 floor within seconds of a test starting and rarely recovered — this is visible in the live 20260630_1930 test, where the deployed runtime pinned osi_gain at 0.08 for ~300 s of a healthy experiment. 1. What was wrong with the current OSI / authority update

The current runtime (m91_adaptive_margin + auth_stability_gain, replayed faithfully by run_current_osi_auth_factor_cases) fails in four structural ways, all visible in the comparison figures below:

  1. The residual branch is biased low by construction. Every update it takes the maximum of ~40 noisy per-bin power ratios and compares it against a percentile-based calibration constant. The maximum of noisy ratios systematically exceeds the calibration, so the branch reports a low margin (≈0.3) on perfectly healthy data, forever. Since the reported margin is min(ST, residual), the bias wins.
  2. The baseline is calibrated during the worst possible seconds. It uses the first 7.5 s of the record — which contain the −14 mm actuator homing ramp — and never revisits the choice, so the "healthy floor" is garbage in every one of these records.
  3. Blind optimism when unobservable. When there is no coherent input, the ST branch reports the cap (0.70) rather than "don't know", so margin and authority decisions are made on fiction in the long command-off stretches of records 1731 and 1930.
  4. The authority law can only creep back. Recovery is a fixed 0.0015/update integrator with no model of what authority would actually be safe. Combined with the biased margin, the deployed test (1930) collapsed 0.3 → 0.08 at t≈90 s and never recovered. The margin also carries ad-hoc shaping (st_power exponent, percentile games) with no physical meaning.

2. The margin being estimated

Same quantity the project already standardizes on: the chordal (normalized-coprime-factor–style) distance of the loop's Nyquist locus to the critical point, evaluated per frequency and minimized over the band [2, 100] Hz (58–62 Hz line-rejected):

b(ω) = |1 + L(ω)| / √(2(1 + |L(ω)|²)) = 1 / (√2 · √(|S(ω)|² + |T(ω)|²)) ,    b = minω b(ω) ≤ 1/√2 ≈ 0.707

with T estimated from the measured dd → dm map and S = 1 − T. Since any strictly proper loop has |L| → 0 somewhere in the band, 1/√2 is the mathematical ceiling; the estimator caps there, and the cap carries the meaning "no evidence of margin deficit", never "measured 0.707". For this rig the nominal (healthy plant tf_sp1_7000, PID P0.15/I20/D0.0015) margin is 0.588 @ 35 Hz; the degraded plant (tf_sp1_5000) gives 0.345 @ 38 Hz.

3. The fable indicator (fable_osi.m)

3.1 Two-scale rolling-STFT architecture

The estimator steps every 0.125 s. The SLOW scale (accuracy): 1 s Hann segments hopped every 0.25 s in a 5 s ring of 17 segment spectra — one new 2048-point FFT per hop (the previous runtime recomputed all 39 segment FFTs of its window at every update, then had to time-slice them across target ticks). The FAST scale (latency, §3.6): 0.25 s segments in a ~0.5 s ring — one 512-point FFT per step. Auto- and cross-spectra are aggregated by medians across segments (robust to one-segment transients), and coherence is bias-corrected using the effective number of independent averages keff (computed from the Hann overlap correlations; keff ≈ 9.1 here).

3.2 Branch A — coherent (S,T) margin, debiased

A bin enters the ST branch only if it passes a null-calibrated coherence gate — the threshold where a truly unrelated bin would pass with probability α = 1%:

P(γ̂² > z | H0) = (1 − z)keff−1  ⇒  γgate = 1 − α1/(keff−1)

and an input-power gate (within 35 dB of the in-band peak). The power gate matters: a single false-coherence bin at an undriven frequency reads |T̂| = huge and would nuke the margin to zero — this exact failure appeared in testing and is why coherence alone is not enough. The margin is the minimum of the 3-bin-median-smoothed chordal curve over gated bins (≥5 required), with a 3-sample temporal median. No percentile shaping, no exponent — the estimate is left unbiased so that its level can be compared against the target honestly.

3.3 Branch B — residual growth at undriven frequencies, evidence-based

Instability that the command doesn't excite shows up as growing output power at quiet bins (dm = S·v under noise v). The branch watches only bins the command does not drive, inside the configured hazard band (default 28–100 Hz — where this loop can actually go unstable; low-frequency harmonic distortion of a strong low-band command is deliberately outside it). Per update:

  1. residual PSD ratio vs a calibrated baseline, self-normalized by the cross-bin quiet median — broadband intensity changes cancel;
  2. robust z-score of the log ratio against the calibration spread (median/MAD);
  3. the branch engages only after z > 3.5 persists for 3 hops at the same frequency (±3 Hz). Until then it reports the cap — zero steady-state bias, which is what the old max-of-ratios branch could not do;
  4. once engaged, the full growth is mapped to margin using the |L| ≈ 1 relation near the critical point (output PSD ∝ |S|², b ∝ 1/|S|):
bres = b0(ω*) / √(growth),    growth = ezmax·σ0

where b0(ω*) is the prior margin curve at the binding bin. Disengagement is hysteretic (z < 2).

3.4 Calibration that defends itself

  • Outlier-rejecting collection: baseline windows must agree with the running reference within 6 dB; if everything gets rejected the reference itself was the outlier (actuator homing) and collection restarts.
  • Excitation-regime rebaseline: the set of command-driven bins changing (a test phase starting/stopping) legitimately moves the quiet-bin floor — and it is an exogenous, observable event: instability grows quiet-bin power but cannot change which bins the command drives. On a sustained excited-set change the baseline is recollected; the ST branch keeps running throughout. This is what lets one calibration-free runtime survive record 1731 (command off for 620 s, then broadband) and the phase-switching 1930 test without false alarms.
  • Gated slow adaptation: when z is quiet, the baseline tracks drift with a 100 s time constant, hard-capped at ±3 dB from calibration so degradation can never be "absorbed".

3.5 Validity semantics

A strict honesty rule throughout: when nothing is measurable the margin is NaN (warm-up, no data) — never a fabricated "nominal"; when only the output floor is observable the margin is the cap with st_valid=false, and the authority law treats those states differently.

3.6 The fast path — damage to authority action in ≤ 0.5 s

The 5 s analysis window cannot flip its median in half a second, so speed comes from a second scale, not from degrading the accurate one. The estimator steps every 0.125 s and keeps a short ring of 0.25 s segments beside the slow ring. Two fast statistics, both CUSUM quickest-change detectors (accumulate max(0, Σ(z−ν)); sustained moderate shifts cross in a few steps, isolated healthy spikes decay):

  1. Pooled FRF-change: d = median over observed bins of |T̂new−T̂slow|²/|T̂slow|², from the NEWEST segment alone — the bin pooling supplies the averaging that a chordal margin from 0.5 s of data cannot. Log-z-scored against its own calibrated healthy spread. A trip additionally requires a margin-degrading direction (bfast < bslow) and an absolutely-concerning fast margin — so the change back to healthy after an event, or a benign shift at safe margins, never sheds.
  2. Quiet-band burst: the newest segment's undriven sub-band powers (five fixed sub-bands of the hazard band) against calibrated levels — divergence-like growth compounds the shed every 0.125 s step.

Fast trips can only ever reduce authority (one decisive drop sized by the fast margin for FRF trips; compounding for burst trips), latch the recovery ceiling, and hand regulation to the slow path. Four gates keep the trip rate at zero on healthy data — each one was added because a real record or a closed-loop scenario demanded it: (i) stand down while the excitation regime is changing or nascent (the input-support mask moving); (ii) stand down when the newest segment's input power leaves [0.25, 4]× its ~3 s average (a fading or bursting command mimics change evidence); (iii) a trip immediately followed by a confirmed regime recalibration is retrospectively diagnosed as the transition itself and undone; (iv) the authority-motion gate (added 2026-07-02): the FRF-change statistic watches the total loop, which includes the authority factor itself, so in closed loop the caller writes the currently applied authority into state.a_cmd and the statistic arms only after the authority has been steady (<fast_amove_frac relative motion) for one full analysis window — the law can therefore never trip on its own regulation moves. Real damage arrives while the authority is static, so the gate costs nothing there; replays where the authority never acted on the plant leave a_cmd unset and keep the detector always armed. Validated result: zero fast trips across all healthy phases of all three records and all healthy synthetic scenarios.

Information limit, stated honestly: when the command has no power near the critical frequency, the only damage signature is the noise-floor growth — for this rig's plant pair that is ~1.5–2× per 0.25 s snapshot, i.e. a 2–3σ event per segment. No detector can certify that in 0.5 s at a near-zero false-alarm rate; the CUSUM accumulates it in ~1.5 s (S4). A truly diverging loop produces huge z and still trips in ~0.4 s regardless of excitation.

4. The target-tracking authority law (fable_auth.m, rewritten 2026-07-02)

Scalar-state supervisory law, updated every 0.125 s OSI step. The law regulates the reported margin onto a target OSI (parameter target, default 0.55): whenever the margin is at or above the target the authority recovers to and holds amax = 1 — a healthy loop runs at full authority; when the margin drops below the target the authority sheds multiplicatively, a ← a·(b/target)p, until the margin climbs back. The closed loop settles where b ≈ target (or at a = 1 when the loop is healthier than the target even at full authority). Contract, in priority order:

4.1 The predicted-safe authority, done correctly

Because authority scales the loop linearly (L(a) = (a/anow)·L̂), the measured loop L̂ = T̂/(1−T̂) at coherent bins yields a predicted margin curve bpred(α) over a 25-point gain grid. One subtlety is essential and easy to get wrong:

The chordal margin is not monotone in loop gain. At very large gain the locus is again "far" from −1 pointwise, so "the largest α whose predicted margin clears the target" can be α = 20 — through an unstable pocket. Since authority moves continuously, only the contiguous safe interval around the current operating point is admissible: shedding walks down to the first safe α below 1; recovery expands upward only through connected safe values. (First drafts of this law froze or slammed on real data until this was fixed — it is the difference between a pointwise distance and a stability statement.)

The prediction is a bound and an accelerator, never a trust anchor: it floors confirmed sheds at 90% of the predicted-safe authority (no pointless slam to amin while the 5 s window flushes) and caps recovery at the safe-interval boundary, linearly interpolated between grid points — the boundary already stands pred_guard (0.03) of margin short of the target crossing, and the up_deadband hysteresis supplies the standoff below it. (The first draft applied an additional ×0.9 haircut on the way up; combined with the coarse gain grid it permanently stranded the authority at ≈0.9 whenever the target sits close to the healthy margin — with target 0.55 against a 0.588 healthy margin the loop could never return to full authority. The margin slack is the principled standoff; the multiplicative haircut double-counted it and is now down-path only.) The prediction is only consulted when the binding frequency is inside the coherently observed band (st_binding); a residual-driven deficit is outside the model's sight, so there the shed proceeds to the power-law floor until the evidence clears.

8. Limitations & deployment notes

  • dd/dm only, Speedgoat-shaped. The estimator honors the existing runtime contract (no fm/dc required). Step mode is fixed-size per call (hop_n samples, one FFT); state is a fixed-size numeric struct, flattenable exactly like prepare_osi_gain_runtime flattens the M9.1 config today. The dd→dm map absorbs the phase lead GT; the margin is therefore the outer (transfer-system) margin — the same quantity the current tests target (target_outer_ncf).
  • Unobservable-band optimism. Where the command has no power and the output floor shows no growth, the margin reads the cap. That is a statement of evidence, not of the true global margin (1930's step phases read 0.707 while the 20 s reference sees ≈0.6). The authority law compensates: recovery in that state is slow, and the residual latch remembers hazards the band cannot currently see.
  • Common-mode blind spot. The residual z-statistic is self-normalized across bins, so a perfectly flat broadband output rise is absorbed by design (that is what makes it immune to intensity changes). Broadband divergence is covered by the calibrated sub-band burst CUSUMs and, when any input is present, by the ST branch; a physically diverging loop also concentrates power at the unstable frequency within a couple of windows, which the z-statistic then sees.
  • Quiet-band regulation tolerance. With no command power at the critical frequency, a mild deficit (< ~0.08 below target for this rig) produces a growth signature beneath any detector's noise floor; the law regulates such deficits to a target−0.08 tolerance band rather than to the target itself (S4). Serious deficits and divergence produce strong signatures and are shed hard and fast. This is an information limit, not a tuning choice.
  • Fast-path guarantee scope. "Authority moves ≤0.5 s after damage" holds when the command excites the critical band (S3 class, and any test with broadband/EQ excitation through the binding region). Quiet-band-only damage takes ~1.5 s (S4 class); truly diverging loops trip in ~0.4 s regardless.
  • Replay ≠ closed loop. On the records, authority did not feed back into the plant. The closed-loop claims rest on Section 5, where the whole chain (estimator → law → loop) runs sample-accurately against a computable truth.
  • Knobs that matter: target (0.55 production default — it must stay below the healthy-loop margin at full authority, 0.588 for this rig, or the law will permanently detune the loop chasing an unreachable margin; 0.30 in the record replays, 0.50/0.55 in the synthetic studies); residual_band_hz (set from where your loop can go unstable); window_s/hop_s (latency vs variance). The full authority tuning surface — smoothness (b_filt_tau_s), drop speed and sizing cadence (down_rate, down_settle_s, re_shed_delta), recovery speed (up_rate, up_prop, up_hold_s, up_rate_blind), anti-flicker (min_step, deadbands, confirm counts), post-event caution (latch constants) — is documented knob-by-knob in the fable_auth.m header; the per-branch estimator knobs in the fable_osi.m header. Tune against real records with fable_tune_explorer (§9).

9. Speedgoat runtime, equivalence & the tuning workflow

The step path is deployed as control_and_HS/OSI/fable_osi_runtime.m — a single %#codegen MATLAB Function body wrapped exactly like the legacy osi_gain_runtime.m: called once per 2048 Hz base-rate sample with scalar dd, dm, en; all configuration arrives as fixed-size parameter arrays built at compile time by prepare_fable_runtime.m (index maps documented there); all estimator state lives in fixed-size persistents and the authority state in scalar persistents; raw samples go into circular rings (no per-tick buffer copy). Outputs: auth, b_osi, b_st, b_res, b_fast, trip_reason, valid, decision, held between internal 0.125 s steps. The enable/pause contract matches the legacy block (en = 0 shadow, 1 active, +2 pause resets the rings but keeps calibration and authority state).

Equivalence, proven. test_fable_runtime_equivalence feeds the same dd/dm stream through the runtime (sample-by-sample) and the desktop fable_osi + fable_auth loop and compares every trace. Result: max|Δ| = 0 (bitwise) on all three experimental records and a synthetic path-coverage stream. Getting to zero required replicating MATLAB's exact even-count median rounding — median() and movmedian() use different formulas (overflow-safe midpoint vs. midpoint anchored at the smaller-magnitude middle value), established by fuzzing and preserved in the runtime's hand-coded helpers. Stage A of the fable_simulink.md verification protocol is therefore complete.

If the target overruns (TET too high), the runtime header contains the ordered playbook: (1) scheduling — move the block to a triggered subsystem or split the hop work across steps (no algorithm change); (2) fable_pred_enable = 0 (drops the prediction grid; the law falls back to power-law regulation); (3) step_s = 0.25 (halves the fast path, doubles trip latency); (4) hop_s = 0.5; (5) narrower band_hz; (6) shorter window_s; (7) fewer alpha_grid points; (8) fewer burst sub-bands. Do not shrink segment_s below 1 s or weaken the coherence/input gates — they are the false-alarm protection, not overhead.

Tuning workflow. fable_tune_explorer replays any record in saved_results/tests/important (selection dialog, index, or path) through the exact runtime function and draws linked-zoom subplots — dm, every OSI branch + the selected margin + the target line, and the authority with trip markers — with your 'osi'/'auth' override structs stamped on the figure. Because the explorer runs the very code the Speedgoat executes, a tuning settled there transfers 1:1 to the target. Re-validate any tuning with fable_synthetic_suite (closed loop) before deploying.
