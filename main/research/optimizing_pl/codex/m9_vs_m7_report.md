## Why M9.1 addresses the M7 issues

- M7 hard-codes a peak band. M9.1 searches 2-100 Hz point by point and reports the frequency that bound the estimate.
- M7 is relative to `b_nom` and `S_pk,ref`. M9.1 uses the absolute phase-aware branch from `S=1-T`, `T=dm/dd_lead` on excited/coherent bins, and uses the residual branch for output-only evidence.
- If the instability is caused by phase delay instead of gain amplification, the `S,T` branch still sees the Nyquist distance shrink because it uses the complex transfer function, not only output amplitude.
- If the dangerous region is actually excited, M9.1 uses the measured complex FRF instead of waiting for a resonance peak to grow.
- If the dangerous region is not excited, M9.1 falls back to input-quiet residual output noise after removing command-correlated output by coherence.
- If residual growth appears at the same frequency as the direct `S,T` branch before `S,T` crosses the relative alarm level, M9.1 allows that residual evidence to pull the margin down early, but not below 80% of the direct `S,T` estimate.
