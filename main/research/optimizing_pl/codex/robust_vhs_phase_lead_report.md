## Interpretation

The optimizer ranks candidates by worst-case margin first and then by full-record time-domain error on the measured/scalar rational cases. A static phase_lead is accepted only if it survives the healthy, damaged, mismatch, scalar-gain, and measured-shape frequency-response envelope.

The safety table is not assumed monotonic by theory. It is an offline verification table for using command attenuation as the single online safety knob.
