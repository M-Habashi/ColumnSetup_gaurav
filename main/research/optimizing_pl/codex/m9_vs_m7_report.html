Method 9 adaptive margin

M9 separates the online evidence into two observability regimes: frequencies where the command input excites the loop enough for a complex closed-loop FRF, and frequencies where the input is quiet so the useful evidence is residual output growth.

Input-excited band

Use branch 2 when \(dd_{\mathrm{lead}}\) has enough power and coherence is acceptable. The estimator reads the command-correlated transfer and converts the complex \(S,T\) pair into an NCF distance.

\[ \widehat T(\omega,t)=\frac{\Phi_{yu}(\omega,t)}{\Phi_{uu}(\omega,t)},\qquad \widehat S(\omega,t)=1-\widehat T(\omega,t) \]

Input-quiet band

Use branch 3 when the command is too weak to identify a transfer at that frequency. The estimator removes command-correlated output and tracks residual/internal output growth over the wide monitored band.

\[ \Phi_{\mathrm{res}}(\omega,t)\approx \Phi_{yy}(\omega,t)\left(1-\gamma^2(\omega,t)\right) \]

Notation

Let \(u=dd_{\mathrm{lead}}\), \(y=dm\), \(d\) be internal disturbance or noise, \(H\) be the plant path from command force/displacement action to measured displacement, and \(C\) be the controller.

\[ L(\omega,t)=C(\omega)H(\omega,t),\qquad S(\omega,t)=\frac{1}{1+L(\omega,t)},\qquad T(\omega,t)=\frac{L(\omega,t)}{1+L(\omega,t)} \]

The measured output is the sum of a command-correlated part and an internally excited part:

\[ y(\omega,t)=T(\omega,t)u(\omega,t)+S(\omega,t)d(\omega,t) \]

Here \(\Phi_{ab}\) means the cross-spectrum between signals \(a\) and \(b\), and \(\Phi_{aa}\) is the autospectrum of \(a\).

Branch 2: input-excited band

Step 1: require identifiable input power

M9 only trusts branch 2 on bins where the input has enough power and the estimated input-output relation is coherent:

\[ \Omega_{\mathrm{exc}}(t)= \left\{\omega: \Phi_{uu}(\omega,t)\ \text{is large enough},\quad \gamma^2(\omega,t)\ge \gamma_{\min} \right\} \]

Step 2: estimate the command-correlated transfer

Using the output equation, the cross-spectrum with the command is:

\[ \Phi_{yu}(\omega,t)= T(\omega,t)\Phi_{uu}(\omega,t) +S(\omega,t)\Phi_{du}(\omega,t) \]

If the internal disturbance is not correlated with the command, \(\Phi_{du}\approx0\). Then:

\[ \widehat T(\omega,t)= \frac{\Phi_{yu}(\omega,t)}{\Phi_{uu}(\omega,t)} \approx T(\omega,t) \]

Step 3: convert \(S,T\) into margin

For unity feedback, \(S=1-T\). The NCF loop distance at one frequency can be written directly from \(S,T\):

\[ b(\omega,t)= \frac{1}{\sqrt{2}\sqrt{|S(\omega,t)|^2+|T(\omega,t)|^2}} \]

M9 uses a high percentile over the excited bins instead of a single noisy maximum:

\[ b_{ST}(t)= \frac{1}{\sqrt{2}\, P_{95,\omega\in\Omega_{\mathrm{exc}}(t)} \left(\sqrt{|\widehat S(\omega,t)|^2+|\widehat T(\omega,t)|^2}\right)} \]

This branch is the phase-aware branch. If the dangerous frequency is externally excited, it can detect margin loss caused by phase delay even before a large output-only resonance is visible.

Branch 3: input-quiet band

Step 1: decompose the output spectrum

When \(u\) and \(d\) are approximately uncorrelated, the total output spectrum is:

\[ \Phi_{yy}(\omega,t)= \underbrace{|T(\omega,t)|^2\Phi_{uu}(\omega,t)}_{\text{command-correlated output}} + \underbrace{|S(\omega,t)|^2\Phi_{dd}(\omega)}_{\text{residual/internal output}} \]

Step 2: use coherence to remove the command-correlated part

\[ \gamma^2(\omega,t)= \frac{|\Phi_{yu}(\omega,t)|^2} {\Phi_{uu}(\omega,t)\Phi_{yy}(\omega,t)} \]

The residual output spectrum is approximated as:

\[ \Phi_{\mathrm{res}}(\omega,t)\approx \Phi_{yy}(\omega,t)\left(1-\gamma^2(\omega,t)\right) \]

Step 3: search the wide residual band

Branch 3 compares the current residual spectrum with the healthy reference spectrum and asks for the largest residual growth over the monitored band:

\[ q(t)= \max_{\omega\in\Omega_{\mathrm{wide}}} \frac{\Phi_{\mathrm{res}}(\omega,t)} {\Phi_{\mathrm{res,ref}}(\omega)} \]

Then it maps the residual growth to a conservative margin proxy:

\[ b_{\mathrm{wide}}(t)= b_0\sqrt{\frac{q_{\mathrm{ref}}}{q(t)}} \]

Why this sees what branch 2 can miss

If a mode grows from internal disturbance or noise, then the residual spectrum contains:

\[ \Phi_{\mathrm{res}}(\omega,t)\approx |S(\omega,t)|^2\Phi_{dd}(\omega) \]

So branch 3 can catch output-only resonance growth even when the command has almost no power at that frequency:

\[ \Phi_{uu}(\omega)\approx0 \]

Can branch 3 replace branch 1?

Theoretically, yes. Branch 1 and branch 3 both read uncommanded output growth. The difference is that branch 1 is a targeted known-mode approximation, while branch 3 is a wide-band residual guard.

Branch 1: known-mode proxy

\[ Spk(t)= \sqrt{ \frac{\max_{\omega\in\Omega_{\mathrm{peak}}}\Phi_{yy}(\omega,t)} {\operatorname{median}_{\omega\in\Omega_{\mathrm{floor}}}\Phi_{yy}(\omega,t)} },\qquad b_{\mathrm{peak}}(t)=b_0\frac{Spk_{\mathrm{ref}}}{Spk(t)} \]

More interpretable when the binding resonance is known and remains in the expected band.

Branch 3: wide residual guard

\[ b_{\mathrm{wide}}(t)= b_0\sqrt{\frac{q_{\mathrm{ref}}}{q(t)}} \]

Broader and safer for shifted or unknown input-quiet modes, but less direct as a calibrated NCF estimate.

Practical conclusion: branch 3 can replace branch 1 for detection, but branch 1 is still valuable when the known binding mode is trusted because its peak/floor calibration is cleaner.
