Method 9 adaptive margin

M9 keeps the useful part of M7, but removes the fixed 35 Hz assumption. It uses a phase-aware closed-loop estimate when the command excites a frequency and a residual output-only estimate when it does not.

Estimator

T = dm/dd_lead, S = 1 - T
NCF = 1/(sqrt(2)*max sqrt(|S|^2 + |T|^2))

Fallback

residual PSD = Pyy*(1 - coherence)
b = b0*sqrt(q_ref/q_now), searched over 2-100 Hz

Branch logic

Branch 2 and branch 3 deliberately look at different parts of the same closed-loop response. With command input u = dd_lead, measured output y = dm, loop transfer L = C H, sensitivity S = 1/(1 + L), and complementary sensitivity T = L/(1 + L), the measured response can be written as:

y(ω,t) = T(ω,t) u(ω,t) + S(ω,t) d(ω,t)

Branch 2: excited bins

This branch is used where the command has enough power. It estimates the command-correlated closed-loop transfer point by point:

T_hat(ω,t) = Phi_yu(ω,t) / Phi_uu(ω,t)
S_hat(ω,t) = 1 - T_hat(ω,t)
b_ST(t) = 1/(sqrt(2) max sqrt(|S_hat|^2 + |T_hat|^2))

If the dangerous frequency is externally excited, this branch sees both magnitude and phase. It can therefore detect a margin loss caused by phase delay even before a large output resonance appears.

Branch 3: unexcited bins

This branch is used as a wide-band output-only guard. It subtracts the output part explained by the command and tracks residual growth:

gamma^2 = |Phi_yu|^2/(Phi_uu Phi_yy)
Phi_res(ω,t) = Phi_yy(ω,t)(1 - gamma^2(ω,t))
q(t) = max Phi_res(ω,t)/Phi_res,ref(ω)
b_wide(t) = b0 sqrt(q_ref/q(t))

If an uncommanded mode grows from internal disturbance, branch 2 may not see it because the growth is not correlated with u. Branch 3 can still see the residual output energy.

Branch 3 can replace branch 1 in theory because both can detect unexcited output growth. The cost is interpretation. Branch 1 is a targeted known-mode proxy: it assumes the binding resonance is in a known peak band and maps its peak/floor ratio to margin. Branch 3 is broader and safer against shifted or unknown modes, but its baseline-normalized residual growth is a less direct NCF estimate.

Branch 1: known resonance, calibrated peak/floor margin proxy
Branch 3: unknown or shifted unexcited mode, wide residual-energy guard

Interpretation

M9 improves the three-case comparison by adding the wide residual branch for low-band operation and the complex S,T branch for excited operation. The same estimator also handles phase-delay failures because the S,T distance uses phase and magnitude together.
