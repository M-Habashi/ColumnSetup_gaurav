Core Equations

fs = 1/dt
segment_n = round(segment_s*fs)
step_n = round(step_s*fs)
n_segment = round((window_s - segment_s)/hop_s) + 1

The OSI estimates the closed-loop transfer from command displacement to measured displacement. In the code, M = Suy/Suu, where Suu is command autospectrum, Syy is measured autospectrum, and Suy is cross spectrum.

g2raw = abs(Suy)^2 / max(Suu*Syy, tiny^2)
gamma2 = max(0, (k_eff*g2raw - 1)/(k_eff - 1))
excited = keep & g2raw > gamma_gate & has_input & not_leak
quiet = res_keep & ~has_input & g2raw < gamma_quiet

The project margin is the normalized coprime-factor style chordal margin. With T = M and S = 1 - T:

b(w) = 1/(sqrt(2)*sqrt(abs(S)^2 + abs(T)^2))
b_st = min_over_excited_bins( masked_median_frequency(b(w)) )
b_osi = min(b_st, b_res), capped by cap = 1/sqrt(2)

The residual branch watches output power that is not explained by the coherent command path.

res = Syy * max(1 - gamma2, residual_floor)
ratio = res / baseline
normq = ratio / max(median(ratio(quiet)), eps)
z = (log(max(normq, eps)) - mu0) / sigma0
growth = exp(max(z_max, 0)*sigma0)
b_res = max(0.05, anchor/sqrt(max(growth, 1)))

The fast quick-dip logic uses CUSUM statistics. Lower drift nu or threshold h makes detection faster and more sensitive.

cus_st = max(0, cus_st + z_d - fast_st_nu)
st_trip = cus_st > fast_st_h & b_fast < b_slow_filt & b_fast < threshold + fast_babs_offset
cus_burst(j) = max(0, cus_burst(j) + z_burst(j) - fast_burst_nu)
burst_trip = any(cus_burst > fast_burst_h)

The authority law regulates b_osi toward prm.target. It lowers authority quickly when margin is low and recovers only after hysteresis and hold-time checks pass.

filt_alpha = 1 - exp(-dt_update/b_filt_tau_s)
b_filt = (1 - filt_alpha)*b_filt + filt_alpha*b
severe = b < sev_frac*target
low = min(b, b_filt) < target - down_deadband
a_pl = a_cont * (max(b_size, 0.02)/target)^down_power
a_cont = min(a_cont, max(a_shed_tgt, a_cont - rate*dt_update))
recovery_rate = up_rate*(1 + up_prop*surplus/target)

Slow ST Branch Parameters

The slow ST branch is the accurate margin level when the command excites the dangerous frequencies. It is the best branch for recovery decisions because it observes the actual coherent transfer T = dm/dd.

ParameterDefaultDefinitionTuning effect
band_hz[2 100]Overall frequency band considered by the OSI.Narrowing reduces cost and ignores irrelevant modes; widening watches more modes but can add noisy bins.
line_reject_hz[58 62]Power-line rejection band removed from slow and fast grids.Move only if electrical line contamination is elsewhere.
segment_s1.0Hann segment length for slow spectra.Keep near 1 s for 1 Hz resolution. Shorter weakens margin frequency resolution.
hop_s0.25Slow spectral refresh cadence. Must be compatible with step_s.Larger is cheaper and smoother but slower; smaller is faster but heavier.
step_s0.125Runtime OSI step cadence and fast path cadence.Larger lowers Speedgoat work; smaller improves quick-dip reaction but costs TET.
window_s5.0Slow ring memory. Produces n_segment median-aggregated segments.Longer gives stable margins; shorter follows changes faster but can false dip.
gamma_alpha0.01False-pass probability used to derive gamma_gate.Lower is stricter, accepting fewer coherent bins.

sidelobe_db25Rejects bins that look like Hann leakage from a nearby stronger bin.Raise to be stricter about leakage; lower to keep more adjacent bins.

Residual Branch Parameters

The residual branch watches the hazard band when the command does not excite it. It is slower than the fast branch because it needs a calibrated quiet-band baseline, but it is the branch that protects against uncommanded growth.

These are mostly scheduling and flattening parameters. They control whether the algorithm fits inside the 2048 Hz real-time budget.

Final Categorized Tuning Table

This table focuses only on parameters that are practical to tune to control OSI behavior. Categories are branch-based plus quick-dip and authority behavior.

Category Main parameters Primary behavior controlled Faster / more protective Smoother / fewer false actions
Slow ST branch window_s, hop_s, margin_filter_n, freq_medfilt_n, gamma_alpha, input_power_range_db, min_bins Accurate coherent margin b_st used for normal regulation and recovery. Lower window_s, lower hop_s, lower margin_filter_n, higher accepted-bin permissiveness. Raise window_s, margin_filter_n, freq_medfilt_n, and min_bins; lower gamma_alpha.
Residual branch residual_band_hz, z_on, z_off, res_on_n, res_min_growth_db, sigma0_floor, regime_hops Quiet-band hazard detection b_res when command excitation does not directly observe the dangerous band.
