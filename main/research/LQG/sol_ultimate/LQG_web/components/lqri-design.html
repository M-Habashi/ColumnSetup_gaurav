Linear Quadratic Regulator with Integral action (LQRI)

LQRI removes the stiffness-dependent steady-state error by making the accumulated output error part of the controller state.

The nominal precompensator gives exact tracking only when the plant model is exact. A stiffness change alters the steady-state gain. The same precompensator can therefore leave a constant offset even when the feedback loop remains stable.

Introduce the integral state η through the tracking error:

η˙=r−y=r−Cx z=[xTη]T,z˙=Aaz+Bau+Ear Aa=[A0−C0],Ba=[B0],Ea=[0I]

The augmented cost penalizes the measured output, accumulated error, and control input:

JI=∫0∞ (xTCTQyCx+qIη2+uTRu)dt

The Riccati equation now uses the augmented matrices. Its solution gives the state gain and the integral gain together:

The output weight Qy and integral-state weight qI are selected independently. MATLAB's built-in lqi function solves every candidate and returns the combined state and integral gain.

Bryson's rule supplies physically scaled starting values from the nominal PID unit-step loop. Let emax be the largest tracking error. Let xI,max be the largest accumulated error and umax the largest PID control input. The raw Bryson weights are normalized by the input weight so that R=1:

Qy,B=1emax2,qI,B=1xI,max2,RB=1umax2 Q¯y,B=(umaxemax)2,q¯I,B=(umaxxI,max)2

Independent multipliers ρy and ρI span two decades below and above unity. This grid initializes a continuous positive log-space refinement without imposing an upper bound on either weight. Costs from different weights are not compared because each pair changes the definition of J. The selected pair instead makes the smallest logarithmic departure from the Bryson scaling while satisfying the NCF requirement.

Every candidate uses the same initial rest condition for a unit reference. If xr and ηr denote the corresponding equilibrium, then the initial deviation is z0=[−xrT−ηr]T. The Riccati solution gives the optimal value J*=z0TPaz0 for that fixed condition.

(Qy*,qI*) =arg minρy,ρI>0 (log10ρy)2+(log10ρI)2 subject to b(LLQRI)=b(LPID)

At the 7k design condition, the normalized NCF values are equal. The independently selected LQRI gain is then held fixed across the stiffness interval. Integral action removes constant offset whenever the augmented closed loop is stable and the actuator is not saturated.
