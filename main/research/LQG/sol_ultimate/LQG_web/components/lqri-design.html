One gradient-optimized LQI for 7k and 5k

The nominal 7k CARE generates one fixed gain. That same gain is differentiated through the 7k and 5k step responses and must stabilize both endpoint plants.

The augmented state contains the identified plant state and the accumulated displacement error. The reference enters the integrator directly; no LQR reference precompensator is used.

z˙=r−Cx u=−Kxx−KIz Q=LQLQT,QI=LI2,R=1

The CARE is solved only for the 7k augmented plant. Its implicit Lyapunov derivative maps both endpoint-response gradients back to the shared trainable weights.

J=12∑p∈{7k,5k}1T∫0T(1−yp)2dt+Ju+Jstable

Ju penalizes only endpoint commands above 2.5, normalized by 0.01. Jstable penalizes any endpoint spectral abscissa above −1 s−1. A result is accepted only when both pole constraints hold and the worst endpoint command is at most 2.51.
