Calculating the LQR normalized coprime-factor margin

The reference precompensator, scalar return ratio, and full coprime-factor operator answer different questions. This article derives each transfer explicitly, shows why the plotted reference response cannot be inserted into the complementary-sensitivity identity, and records the normalized full-state calculation used in this report.

The LQR tracker has separate feedforward and feedback paths

The precompensator acts only on the reference. The gain K closes the robustness-determining feedback loop.

Full-state LQR reference trackerfeedforward tracking · negative state feedback
Gx(s)=[sI−A]−1B u=N¯r−Kx y=Cx

The feedforward gain N¯ changes reference tracking and the requested command. It does not appear in the feedback return ratio, characteristic equation, gain margin, phase margin, or feedback NCF margin.

Deriving the actual reference/output response

The plotted step response includes the 7k precompensator. Its transfer is not complementary sensitivity.

Substitute the control law into x=Gxu:

x=Gx(N¯r−Kx) (I+GxK)x=GxN¯r

Define the physical output plant Gy=CGx and the scalar actuator return ratio L=KGx. The matrix inversion lemma gives

yr=Tr=N¯Gy1+L

The nominal precompensator is selected so that Tr(0)=1. This is a tracking condition, not a statement that the plotted curve equals L/(1+L).

Why the naive reconstruction fails—and the corrected one works

The identity used to recover an open loop depends on which closed-loop transfer was measured.

For the complementary sensitivity at a feedback loop break,

TL=L1+L L=TL(I−TL)−1

The plotted transfer is Tr, not TL. Substituting it into Tr/(1−Tr) incorrectly treats the prefiltered physical output as the loop-break complementary sensitivity. At DC, the nominal tracking condition makes the denominator zero, so the false reconstruction produces infinite DC loop gain.

If the nominal physical plant and precompensator are known, the correct scalar reconstruction follows directly from the reference-response equation:

L=N¯GyTr−1

This reconstruction requires the same N¯ and Gy used to generate the response. It becomes poorly conditioned where Tr is small. The report nevertheless uses this corrected reconstruction as requested, then checks it point by point against L=KGx before calculating the margin.

The scalar return ratio is not the full NCF calculation

Gain and phase margins depend on L. The full normalized coprime-factor margin depends on the plant and controller factors separately.

The primary report comparison uses the same normalized loop expression for PID and LQR:

bproxy=minω|1+L(jω)|2(1+|L(jω)|2)

For LQR, L in this expression is the return ratio reconstructed from the closed-loop response. When the loop gain becomes small, the expression approaches 1/2; this explains the value near 0.707. It is a fair scalar loop comparison when the identical formula and frequency band are used for both controllers, but it is not the full factor-based margin below.

For the normalized full-state plant Gn and its corresponding feedback gain Kn, construct

TNCF=[IKn](I+GnKn)−1[IGn] γNCF=||TNCF||∞ bNCF=1γNCF

The factors [I;Kn] and [I,Gn] cannot be recovered from the scalar product L=KnGn alone. Different plant/controller factorizations can have the same return ratio and different full NCF margins.

Full-state coordinates must be normalized

Raw identified states have different units and arbitrary realization scales. A full-state NCF value changes under a non-unitary state rescaling unless the uncertainty coordinates are fixed.

The report uses one normalization calculated from the nominal 7k continuous-time plant. Let the controllability Gramian satisfy

AWc+WcAT+BBT=0 Dx=diag(diag(Wc)) xn=Dx−1x Gn=Dx−1Gx,Kn=KDx

The transformation preserves the actuator return ratio exactly:

KnGn=KDxDx−1Gx=KGx=L

The same nominal 7k matrix Dx is retained from 7k through 5k. Recomputing it for every stiffness would change the uncertainty definition along with the plant and contaminate the robustness trend.

Reproducible calculation procedure

The report generator evaluates the reconstructed loop metric and the secondary exact norm independently at 101 stiffness conditions.

  1. Interpolate the identified A(α),B(α),C(α) matrices between 7k and 5k.
  2. Keep the optimized gain K and the nominal normalization Dx fixed.
  3. Calculate the closed-loop reference transfer Tr and reconstruct Lrec using N¯Gy/Tr−1.
  4. Verify the sampled reconstruction against KGx, then minimize the normalized scalar expression over 0.1–80 Hz.
  5. Separately build Gn,Kn and the complete TNCF interconnection.
  6. Remove only numerical pole-zero cancellations with a tolerance of 10−9, then use MATLAB hinfnorm to find the global H∞ norm.
  7. Keep the reconstructed scalar margin as the primary display. Retain bNCF=1/γNCF as a secondary diagnostic and calculate gain and phase margins from the return ratio.
Where the precompensator is used

The 7k N¯ remains in the closed-loop step and dashed command calculations. It is intentionally excluded from the feedback robustness interconnection because it lies outside the feedback loop.
