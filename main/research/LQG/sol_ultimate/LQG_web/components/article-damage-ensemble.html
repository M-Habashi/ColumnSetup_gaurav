Classical LQR regulation

For one fixed specimen stiffness, the Riccati equation determines a feedback law that returns the system to its equilibrium while limiting control effort.

Classical LQR state-feedback loopzero-reference regulation · full-state feedback

Consider the linear plant x˙=Ax+Bu. The state x represents departure from the desired equilibrium. An initial condition x(0)=x0 produces a transient response. The controller must suppress this response without demanding excessive actuator motion. This requirement is expressed by the infinite-horizon cost

J= ∫0∞ ( xTQx + uTRu ) dt

The matrix Q weights state error. The matrix R weights control effort. The optimization selects the complete input history u(t) that minimizes both penalties. Under the usual stabilizability and detectability conditions, the solution is the state-feedback law u=−Kx. It makes the closed-loop state approach zero. The cost accumulates the weighted error and effort throughout this return.

The gain follows from the continuous-time algebraic Riccati equation

ATP +PA − PB R−1 BTP +Q=0 K= R−1 BTP

The plant matrices A and B are specified. The weights Q and R are also specified. The symmetric matrix P remains unknown. For n states, it contains n(n+1)/2 independent unknowns. The Riccati equation solves for them. The feedback gain K is then obtained directly. The minimum cost for a given initial condition is J*=x0TPx0.

Now assume that the complete state vector is available to the controller. The same regulation objective can be expressed through a selected plant output y=Cx. The matrix C maps the state to that output. Introduce the positive-semidefinite output weight Qy. The performance objective becomes

Jy= ∫0∞ ( yTQyy +uTRu )dt = ∫0∞ ( xTCTQyCx +uTRu )dt

The output formulation has the same LQR structure. Its effective state weight is Q=CTQyC. Therefore the output-weighted Riccati equation and optimal control law are

ATPy +PyA −PyB R−1 BTPy +CTQyC =0 Ky= R−1 BTPy u=−Kyx

The state vector is x∈Rn. The control input is u∈Rm. The selected output is y∈Rp. Accordingly, C∈Rp×n selects or combines the states that matter to the output objective.

The output weight Qy∈Rp×p is chosen by the designer. The input weight R∈Rm×m is also chosen. The symmetric matrix Py is the only Riccati unknown. It has n(n+1)/2 independent elements. The gain Ky∈Rm×n is calculated from that solution.

The difference between the two formulations is only the performance weight. The first formulation assigns weights directly to the states through Q. The second assigns weights to selected outputs through Qy. Both produce full-state feedback of the form u=−Kx. If Q=CTQyC, they produce the same optimal gain.

Steady-state error and the reference gain

The LQR feedback gain regulates the state toward zero. A separate reference gain is required when the desired output is a nonzero constant.

The law u=−Kx contains no reference signal. Therefore it solves a regulation problem rather than a setpoint-tracking problem. Introduce a constant desired output r and the feedforward gain N through

u=−Kx+Nr

Assume A−BK is stable. Also assume the plant has no direct feedthrough, so y=Cx. For a constant reference, the steady-state equations are

0=(A−BK)xss+BNr xss=− (A−BK)−1 BNr
yss=− C (A−BK)−1 BNr ess=r−yss =[I+C (A−BK)−1 BN]r
LQR reference precompensatoru = −Kx + Nr

Choose N so that yss=r. The nominal steady-state error then becomes zero. The required closed-form gain is

N=− [C (A−BK)−1 B] −1

Here r∈Rp is the desired output. The precompensator N∈Rm×p maps that reference to the plant input. For a single-input single-output plant, N is a scalar. The matrix inverse above requires a square nonsingular steady-state input-output map.

This gain cancels steady-state error only for the nominal model and a constant reference. It does not reject an unknown constant disturbance. It also cannot correct a stiffness-dependent modeling error. Integral action is introduced when those forms of offset rejection are required.

Add specimen stiffness to the cost

Write α = ks/ks0, where ks is the current specimen stiffness, ks0 is its initial stiffness, α = 1 is the undamaged condition, and αmin is the lowest stiffness retained in the model.

J(K)= ∫ αmin 1 p(α) ∫0∞ ( zαT Q zα + uαT R uα ) dtdα

The inner integral is the familiar LQGI cost at one fixed residual stiffness α. The new outer integral repeats that evaluation over the stiffness interval and combines the results using p(α).

What the added integral means

The mathematical change is small but precise: K is no longer selected from only one plant. The same K must act on every stiffness-dependent augmented model Aa(α), Ba(α).

The role of p(α)

p(α) is the stiffness weighting. If it is uniform, every residual stiffness is valued equally. If it is concentrated near small α, the design gives more importance to damaged conditions. It is normally normalized so that its integral from αmin to 1 equals one.

The role of one common K

For each α, zα and uα follow a different plant response, but the feedback law remains uα = −Kzα. The optimization changes K until the weighted sum of all these time-domain costs is minimized.

In practice, approximate the outer integral using stiffness samples αi and quadrature weights wi:

J(K) ≈ ∑i=1N wi Jαi (K)

This is generally not solved by inserting the outer integral into one ordinary CARE, because Aa(α) and Ba(α) vary with stiffness. Instead, one searches for a common K while evaluating the cost of that same gain at all selected stiffness values.
