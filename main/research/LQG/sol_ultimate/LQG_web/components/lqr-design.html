LQR Design

The nominal LQR is designed to reproduce the saved PID controller's loop-only normalized NCF measure. Its feedback and reference gains are then held fixed while the specimen stiffness changes.

For each trial ratio between the output and input penalties, define Q=CTQyC. The corresponding infinite-horizon objective is

J=∫0∞ (xTCTQyCx +uTRu)dt

The algebraic Riccati equation is solved for every trial. Each solution gives a matrix P, a feedback gain K=R−1BTP, and a nominal reference gain N.

The comparison uses the exact calculation in the main identification script. For either open-loop return ratio L, it finds the smallest normalized distance to the critical point over the saved frequency band:

b(L)=min0.1≤f≤80Hz |1+L(j2πf)|2(1+|L(j2πf)|2)

The PID return ratio is LPID=CPIDG. The LQR return ratio is LLQR=KGx, where Gx maps the plant input to the full state.

ρ*=arg minρ |b(LLQR(ρ)) −b(LPID)| ,ρ=Qy/R

The selected penalty ratio minimizes the absolute margin difference. The accepted difference is at most 0.01. The plot then reuses the resulting K and N across the stiffness interval; only the plant changes.
