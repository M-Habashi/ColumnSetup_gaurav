Modeling guide

Robust to what, exactly?

An H∞ label does not create robustness. The generalized plant has to say which changes are correlated physics, which are unexplained dynamics, and which are nonlinear limits that a linear norm cannot guarantee.

First-study rule

Put the validated specimen coordinate inside synthesis. Use gain, delay, noise, and saturation as explicit stress tests first. Add another uncertainty block only when data show it is needed.

Separate knowledge from ignorance

The 7k–5k motion is measured structure. Residual high-frequency error is uncertainty. Treating both as one generic multiplicative envelope throws away the most useful information in the project.

KNOWN SHAPE

Specimen coordinate

One correlated real parameter moves the identified mass, damping, stiffness, and state-space coefficients.

REAL SCALE

Gain amplification

A bounded real block is appropriate only when the error is essentially static over frequency.

UNKNOWN SHAPE

Residual dynamics

A norm-bounded dynamic block covers FRF error left after the specimen model is removed.

NONLINEAR LIMIT

Saturation

The 2.5 command cap is a trajectory constraint, not an ordinary H∞ guarantee.

A later structured model could use

Δ=diag(δθIr,δgIq,Δm(s),Δτ(s))

That is a clean uncertainty taxonomy, but it is not the recommended first synthesis. The first study should isolate the specimen-sensitivity idea rather than make every block active at once.

Use one dimensionless specimen coordinate

A repeated real parameter preserves correlation: every place where the specimen change enters the model moves together.

θ=p−p7p5−p7,θ=0 at 7k,θ=1 at 5k

The scheduling quantity p may ultimately be pressure, measured stiffness, or a fitted coordinate from (m,c,k). It should be chosen by cross-validation, not by naming whichever sensor is convenient.

Two endpoints are not validation

Any two models define a line. Identify at least one intermediate condition, then keep another condition unseen until the controller and weights are frozen.

Gain amplification needs the right model

If the amplitude change is flat with frequency, a real scalar is simple and physically interpretable. If amplitude and phase change with frequency, it is not “just gain.”

Static real amplification

g=g0(1+ρgδg),|δg|≤1

Use this for calibrated load-cell or actuator-gain variation whose phase is unchanged.

Frequency-dependent amplification

G=G0[1+WmΔm],||Δm||∞≤1

Use this only for the residual after the known specimen trend is removed.

The local 9.27 dB / 11.66° endpoint difference shows why a lone scalar-gain sweep is inadequate. A disk gain/phase perturbation can be a useful stress test, but it should not replace the measured family.

Fit residual dynamics after the physics model

For output multiplicative uncertainty, the uncertainty weight must upper-bound the relative model error over the declared band.

|Wm(jω)|≥maxθ|G(jω,θ)−G0(jω,θ)G0(jω,θ)| ||WmT||∞<1for small-gain robust stability

Near nominal zeros, relative error becomes ill-conditioned. Fit an additive envelope there. Always plot the data and the fitted upper bound together; a smooth weight that cuts through the data is not a certificate.

Delay uncertainty is phase uncertainty with a known shape

A delay error grows with frequency until its relative error reaches two. A low-order Padé model may be convenient for synthesis, but it is not an all-frequency bound.

|e−jωδτ−1|=2|sin(ωδτ2)|≤min(ωΔτ,2)

Time-varying delay also needs a rate or jitter description. Prior RTHS studies show that feedback H∞ alone does not erase delay; prediction and synchronization are separate mechanisms. For the first study, measure delay/jitter and use them as held-out stress tests rather than adding a predictor to the proposed controller.

The 2.5 command is not an H∞ theorem

The H∞ norm is an induced L2 gain. A persistent step is not in L2 on an infinite horizon, and a small command weight does not imply a pointwise actuator limit.

gu(K)=maxθ∈[0,1],t∈[0,T]|ustep(t;θ,K)|−2.5≤10−2

The engineering target remains 2.5. The accepted 10−2 is the solver feasibility residual, so a 2.51 result must be labeled tolerance-active rather than silently called 2.5. Simulate raw and saturated commands and report both.
