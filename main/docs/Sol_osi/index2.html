Experimental Inner-Loop System Formulation

The inner loop comprises a PID controller, an experimentally identified plant, adaptive gain scaling, and negative feedback.

Course notationUse u and y
command displacement$d_d \equiv u$
measured displacement$d_m \equiv y$
Experimental Inner Displacement-Control Loopclosed-loop signal topology

We call the experimentally identified plant $H(s,k)$. It maps the internal PID output $v$ to the measured response $y$, while $k$ identifies the current stiffness condition between 7k and 5k.

\[H(s,k)=\frac{Y(s)}{V(s)}\] The plant seen by the PID. Frequency enters through $s=j\omega$; stiffness enters through $k$.

The PID and plant multiply to form the open-loop transfer function. The adaptive factor $\alpha\in[0.02,1]$ scales the controller’s influence; $\alpha=1.00$ means full PID gain.

\[L(s,\alpha,k)=\alpha\,C(s)\,H(s,k)\] In the code, the healthy full-gain loop corresponds to $L_0(s)=C(s)H(s,7\mathrm{k})$.

Closing the negative-feedback loop gives the command → measurement response:

\[T(s,\alpha,k)=\frac{Y(s)}{U(s)}=\frac{L(s,\alpha,k)}{1+L(s,\alpha,k)}\] Both $\alpha$ and $k$ affect $T$ through the open loop $L$.

Short-Time Spectral Estimation of Interface Response

OSI updates at 0.125 s intervals using the most recent 0.5 s window of command and measured displacement data.

01append 0.125 s
02keep 0.5 s
03apply Hann window
04take FFT

Let $u[n]$ be command displacement and $y[n]$ be measured displacement. A Hann window $w[n]$ reduces edge discontinuities before the FFT:

\[U[k]=\operatorname{FFT}\{w[n]u[n]\},\qquad Y[k]=\operatorname{FFT}\{w[n]y[n]\}\]

At time step $n$, the instantaneous input-power, output-power, and cross-power terms are

\[p_u[n]=|U|^2,\qquad p_y[n]=|Y|^2,\qquad c_{yu}[n]=Y\,U^*\] $^*$ means complex conjugate.

One window is noisy, so each spectrum is .

Exponential smoothing combines the newest value with the previous estimate. It is a compact memory: recent windows matter most, but older windows do not disappear instantly.
\[S_{uu}[n]=\bigl(1-\eta_s\bigr)S_{uu}[n-1]+\eta_s p_u[n]\] \[S_{yy}[n]=\bigl(1-\eta_s\bigr)S_{yy}[n-1]+\eta_s p_y[n]\] \[S_{yu}[n]=\bigl(1-\eta_s\bigr)S_{yu}[n-1]+\eta_s c_{yu}[n]\] $n$ is the current time step and $n-1$ is the previous step. The spectral smoothing factor used here is $\eta_s=0.39$.

Confidence-Weighted Coherent Identification of Closed-Loop Dynamics

The coherent branch estimates the closed-loop response from the command–measurement relationship. It then blends that estimate with the known healthy model.

asks: “At this frequency, how consistently does the input explain the output?”

Coherence ranges from 0 to 1. A value near 1 means the input and output have a strong, repeatable linear relationship at that frequency. A value near 0 means the ratio (Y/U) should not be trusted.
\[\gamma^2(\omega)=\frac{|S_{yu}(\omega)|^2}{S_{uu}(\omega)S_{yy}(\omega)},\qquad 0\le \gamma^2\le1\]

Coherence alone is insufficient, so OSI gates it with input leverage for two reasons:

  1. Feedback-created coherence. At frequencies with high loop gain, measurement noise can drive the feedback loop and create high coherence between feedback-related signals even when the intended external excitation is absent. The resulting relationship is driven mainly by noise and can produce a misleading transfer-function estimate.
  2. Division by weak input power. Forming a transfer-function ratio requires division by the input spectrum. When $S_{uu}$ is very small, numerical roundoff, measurement noise, spectral leakage, and ordinary estimation fluctuations can be greatly magnified.

The leverage factor therefore reduces confidence in frequency bins that do not contain meaningful input power. It cannot by itself distinguish strong feedback-correlated noise from intentional excitation.

First define the relative input power $p_{rel}(\omega)$: the power in the current frequency bin divided by the power in the strongest bin.

\[p_{rel}(\omega)=\frac{S_{uu}(\omega)}{\max_{\nu}S_{uu}(\nu)}\] $p_{rel}=1$ at the strongest input frequency and approaches 0 where input power is weak.

Next, $p_{floor}$ is a small positive floor ($10^{-3}$ here) that prevents tiny input values from receiving high trust. The input leverage $\ell(\omega)$ maps relative power to a number between 0 and 1:

\[\ell(\omega)=\frac{p_{rel}(\omega)}{p_{rel}(\omega)+p_{floor}}\]

Finally, $A$ is one activity score for the entire time window: $A=0$ means the command is quiet and $A=1$ means it is strongly driven. Stage 06 gives its exact RMS-based definition. The per-frequency confidence $c(\omega)$ combines activity, coherence, and leverage:

\[c(\omega)=\underbrace{A}_{\text{activity}}\;\underbrace{\gamma^2(\omega)}_{\text{coherence}}\;\underbrace{\ell(\omega)}_{\text{input leverage}}\]

The spectra now provide the raw measured closed-loop estimate $\widehat T(\omega)$:

\[\widehat T(\omega)=\frac{S_{yu}(\omega)}{S_{uu}(\omega)}\]

OSI also forms a model prior. It scales the healthy loop $L_0(\omega)$ by the currently applied adaptive gain $\alpha$, then converts that loop to its closed-loop response $T_{prior}(\omega)$. Here $\alpha$ is the applied a_cmd value: $\alpha=1.00$ means full PID gain, and it changes only if the separate adaptive-gain controller changes a_cmd. The estimator clamps the received value to $0.02\le\alpha\le1$:

\[L_{prior}(\omega)=\alpha L_0(\omega),\qquad T_{prior}(\omega)=\frac{L_{prior}(\omega)}{1+L_{prior}(\omega)}\]

The confidence $c(\omega)$ chooses how far the usable response $\widehat T_{use}(\omega)$ moves from the model prior toward the measured estimate. The final symbol $\widehat L(\omega)$ is the reconstructed open loop:

\[\widehat T_{use}(\omega)=c(\omega)\widehat T(\omega)+[1-c(\omega)]T_{prior}(\omega)\] \[\widehat L(\omega)=\frac{\widehat T_{use}(\omega)}{1-\widehat T_{use}(\omega)}\] The second equation is simply $T=L/(1+L)$ solved for $L$.

Chordal-Distance Formulation of the Online Stability Indicator

At each frequency, OSI evaluates the separation between the estimated loop and the critical feedback condition; the minimum separation defines the reported margin.

The closed-loop denominator is $1+L$. Instability becomes possible when $L(j\omega)$ approaches $-1$, because then $1+L\to0$.

Define $b(\omega,\alpha,k)$ as the normalized distance from that critical condition at frequency $\omega$, adaptive gain $\alpha$, and plant condition $k$:

\[b(\omega,\alpha,k)=\min\!\left(\frac{|1+L(j\omega,\alpha,k)|}{\sqrt{2\left(1+|L(j\omega,\alpha,k)|^2\right)}},\;\frac{1}{\sqrt2}\right)\] This normalized chordal margin stays between 0 and $1/\sqrt2\approx0.707$.

Let $\Omega$ be the usable 2–100 Hz band after excluding the 58–62 Hz line-noise bins. The operator $\operatorname{median}_3$ is a three-bin median filter that suppresses isolated spikes. The online stability indicator $b_{ST}$ is then the weakest filtered margin in $\Omega$:

\[b_{ST}=\min_{\omega\in\Omega}\;\operatorname{median}_3\{b(\omega)\}\]
