Experimental Inner-Loop System Formulation

The inner loop comprises a PID controller, an experimentally identified plant, adaptive gain scaling, and negative feedback.

Course notationUse u and y
command displacement$d_d \equiv u$
measured displacement$d_m \equiv y$
Experimental Inner Displacement-Control Loopclosed-loop signal topology

We call the experimentally identified plant $H(s,k)$. It maps the internal PID output $v$ to the measured response $y$, while $k$ identifies the current stiffness condition between 7k and 5k.

\[H(s,k)=\frac{Y(s)}{V(s)}\] The plant seen by the PID. Frequency enters through $s=j\omega$; stiffness enters through $k$.

The PID and plant multiply to form the open-loop transfer function. The adaptive factor $\alpha\in[0.02,1]$ scales the controller’s influence; $\alpha=1.00$ means full PID gain.

\[L(s,\alpha,k)=\alpha\,C(s)\,H(s,k)\] In the code, the healthy full-gain loop corresponds to $L_0(s)=C(s)H(s,7\mathrm{k})$.

Closing the negative-feedback loop gives the command → measurement response:

\[T(s,\alpha,k)=\frac{Y(s)}{U(s)}=\frac{L(s,\alpha,k)}{1+L(s,\alpha,k)}\] Both $\alpha$ and $k$ affect $T$ through the open loop $L$.

Short-Time Spectral Estimation of Interface Response

OSI updates at 0.125 s intervals using the most recent 0.5 s window of command and measured displacement data.

01append 0.125 s
02keep 0.5 s
03apply Hann window
04take FFT

Let $u[n]$ be command displacement and $y[n]$ be measured displacement. A Hann window $w[n]$ reduces edge discontinuities before the FFT:

\[U[k]=\operatorname{FFT}\{w[n]u[n]\},\qquad Y[k]=\operatorname{FFT}\{w[n]y[n]\}\]

At time step $n$, the instantaneous input-power, output-power, and cross-power terms are

\[p_u[n]=|U|^2,\qquad p_y[n]=|Y|^2,\qquad c_{yu}[n]=Y\,U^*\] $^*$ means complex conjugate.

One window is noisy, so each spectrum is . Throughout this lesson, $\Phi$ denotes a power or cross spectrum; $S$ is reserved for the feedback sensitivity function.

Exponential smoothing combines the newest value with the previous estimate. It is a compact memory: recent windows matter most, but older windows do not disappear instantly.
\[\Phi_{uu}[n]=\bigl(1-\eta_s\bigr)\Phi_{uu}[n-1]+\eta_s p_u[n]\] \[\Phi_{yy}[n]=\bigl(1-\eta_s\bigr)\Phi_{yy}[n-1]+\eta_s p_y[n]\] \[\Phi_{yu}[n]=\bigl(1-\eta_s\bigr)\Phi_{yu}[n-1]+\eta_s c_{yu}[n]\] $n$ is the current time step and $n-1$ is the previous step. The spectral smoothing factor is $\eta_s=0.39$. In MATLAB, $\Phi_{uu}$, $\Phi_{yy}$, and $\Phi_{yu}$ are stored as state.Suu, state.Syy, and state.Syu.

Confidence-Weighted Coherent Identification of Closed-Loop Dynamics

The coherent branch estimates the closed-loop response from the command–measurement relationship. It then blends that estimate with the known healthy model.

asks: “At this frequency, how consistently does the input explain the output?”

Coherence ranges from 0 to 1. A value near 1 means the input and output have a strong, repeatable linear relationship at that frequency. A value near 0 means the ratio (Y/U) should not be trusted.
\[\gamma^2(\omega)=\frac{|\Phi_{yu}(\omega)|^2}{\Phi_{uu}(\omega)\Phi_{yy}(\omega)},\qquad 0\le \gamma^2\le1\]

Coherence alone is insufficient, so OSI gates it with input leverage for two reasons:

  1. Feedback-created coherence. At frequencies with high loop gain, measurement noise can drive the feedback loop and create high coherence between feedback-related signals even when the intended external excitation is absent. The resulting relationship is driven mainly by noise and can produce a misleading transfer-function estimate.
  2. Division by weak input power. Forming a transfer-function ratio requires division by the input spectrum. When $\Phi_{uu}$ is very small, numerical roundoff, measurement noise, spectral leakage, and ordinary estimation fluctuations can be greatly magnified.

The leverage factor therefore reduces confidence in frequency bins that do not contain meaningful input power. It cannot by itself distinguish strong feedback-correlated noise from intentional excitation.

First define the relative input power $p_{rel}(\omega)$: the power in the current frequency bin divided by the power in the strongest bin.

\[p_{rel}(\omega)=\frac{\Phi_{uu}(\omega)}{\max_{\nu}\Phi_{uu}(\nu)}\] $p_{rel}=1$ at the strongest input frequency and approaches 0 where input power is weak.

Next, $p_{floor}$ is a small positive floor ($10^{-3}$ here) that prevents tiny input values from receiving high trust. The input leverage $\ell(\omega)$ maps relative power to a number between 0 and 1:

\[\ell(\omega)=\frac{p_{rel}(\omega)}{p_{rel}(\omega)+p_{floor}}\]

Finally, $A$ is one activity score for the entire time window: $A=0$ means the command is quiet and $A=1$ means it is strongly driven. Stage 06 gives its exact RMS-based definition. The per-frequency confidence $c(\omega)$ combines activity, coherence, and leverage:

\[c(\omega)=\underbrace{A}_{\text{activity}}\;\underbrace{\gamma^2(\omega)}_{\text{coherence}}\;\underbrace{\ell(\omega)}_{\text{input leverage}}\]

The spectra now provide the raw measured closed-loop estimate $\widehat T(\omega)$:

\[\widehat T(\omega)=\frac{\Phi_{yu}(\omega)}{\Phi_{uu}(\omega)}\]

OSI also forms a model prior. It scales the healthy loop $L_0(\omega)$ by the currently applied adaptive gain $\alpha$, then converts that loop to its closed-loop response $T_{prior}(\omega)$. Here $\alpha$ is the applied a_cmd value: $\alpha=1.00$ means full PID gain, and it changes only if the separate adaptive-gain controller changes a_cmd. The estimator clamps the received value to $0.02\le\alpha\le1$:

\[L_{prior}(\omega)=\alpha L_0(\omega),\qquad T_{prior}(\omega)=\frac{L_{prior}(\omega)}{1+L_{prior}(\omega)}\]

The confidence $c(\omega)$ chooses how far the usable response $\widehat T_{use}(\omega)$ moves from the model prior toward the measured estimate. The final symbol $\widehat L(\omega)$ is the reconstructed open loop:

\[\widehat T_{use}(\omega)=c(\omega)\widehat T(\omega)+[1-c(\omega)]T_{prior}(\omega)\] \[\widehat L(\omega)=\frac{\widehat T_{use}(\omega)}{1-\widehat T_{use}(\omega)}\] The second equation is simply $T=L/(1+L)$ solved for $L$.

Chordal-Distance Formulation of the Online Stability Indicator

At each frequency, OSI evaluates the separation between the estimated loop and the critical feedback condition; the minimum separation defines the reported margin.

The closed-loop denominator is $1+L$. Instability becomes possible when $L(j\omega)$ approaches $-1$, because then $1+L\to0$.

Define $b(\omega,\alpha,k)$ as the normalized distance from that critical condition at frequency $\omega$, adaptive gain $\alpha$, and plant condition $k$:

\[b(\omega,\alpha,k)=\min\!\left(\frac{|1+L(j\omega,\alpha,k)|}{\sqrt{2\left(1+|L(j\omega,\alpha,k)|^2\right)}},\;\frac{1}{\sqrt2}\right)\] This normalized chordal margin stays between 0 and $1/\sqrt2\approx0.707$.

Let $\Omega$ be the usable 2–100 Hz band after excluding the 58–62 Hz line-noise bins. The operator $\operatorname{median}_3$ is a three-bin median filter that suppresses isolated spikes. The identification branch keeps its margin as a curve over $\Omega$:

\[b_{ST}(\omega)=\operatorname{median}_3\{b(\omega)\},\qquad\omega\in\Omega\] The reduction $\min_{\omega\in\Omega}$ is deferred to Section 06, after both branches have been fused bin by bin.

Residual Output-Energy Inference under Weak Excitation

When command excitation is insufficient for coherent identification, OSI evaluates changes in measured output spectra relative to a healthy reference.

Let $r=1,2,3$ index the first three non-overlapping 0.5 s reference windows, which are assumed to represent the healthy loop. For window $r$, $y_r[n]\equiv d_{m,r}[n]$ is its measured-displacement segment and $Y_r(\omega)$ is the FFT of that segment after applying the estimator window $w[n]$. The median reference power is denoted by $\Phi_{yy,\mathrm{ref}}(\omega)$:

\[Y_r(\omega)=\mathcal{F}\!\left\{w[n]\,y_r[n]\right\},\qquad y_r[n]\equiv d_{m,r}[n]\] \[\Phi_{yy,\mathrm{ref}}(\omega)=\operatorname{median}_{r=1,2,3}\left\{|Y_r(\omega)|^2\right\}\]

For every later window, the observed ratio $q_{obs}(\omega)$ divides the current smoothed output power by that fixed healthy-reference power:

\[q_{obs}(\omega)=\frac{\Phi_{yy}(\omega)}{\Phi_{yy,\mathrm{ref}}(\omega)}\] A value near 1 resembles the healthy reference. Persistent growth suggests changed loop dynamics.

OSI represents damage-like loop growth with a frequency-dependent scale $\rho(\omega)$. For each of 25 candidate values between 0.5 and 6, the modeled output power $\Phi_{yy,\mathrm{model}}(\omega,\rho)$ is normalized by the same healthy-reference power used in $q_{obs}(\omega)$. The resulting modeled ratio is $q_{model}(\omega,\rho)$:

\[q_{model}(\omega,\rho)=\frac{\Phi_{yy,\mathrm{model}}(\omega,\rho)}{\Phi_{yy,\mathrm{ref}}(\omega)} =\left|\frac{1+L_0(\omega)}{1+\alpha\rho L_0(\omega)}\right|^2\] \[\Omega=\left\{\omega=2\pi f:\;2\,\mathrm{Hz}\le f\le100\,\mathrm{Hz},\quad f\notin[58,62]\,\mathrm{Hz}\right\}\] \[\rho_{best}(\omega)=\arg\min_\rho \left|\log q_{obs}(\omega)-\log q_{model}(\omega,\rho)\right|, \qquad\omega\in\Omega\] Every usable frequency in $\Omega$ independently selects its best candidate $\rho$.

The separate quiet set $\mathcal Q$ supplies a scalar reference ratio used by the recovery criterion of Section 06. It does not restrict the frequency-by-frequency fit:

\[\mathcal Q=\left\{\omega=2\pi f:\;28\,\mathrm{Hz}\le f\le44\,\mathrm{Hz}\right\}\] \[r_{\mathcal Q}=\operatorname{median}_{\omega\in\mathcal Q}q_{obs}(\omega)\] $\Omega$ fits $\rho(\omega)$; $\mathcal Q$ only supports the quiet-reference and recovery logic.

The fitted curve moves toward $\rho_{best}(\omega)$ with a 0.84 s update time constant while activity is present. It decays back toward the healthy value $\rho=1$ with a 2 s time constant whenever the recovery criterion of Section 06 holds:

\[\tau_{\rho,\mathrm{update}}=0.84\,\mathrm{s}, \qquad \tau_{rec}=2\,\mathrm{s}\]

The residual margin $b_{res}(\omega)$ is the chordal margin predicted by the frequency-dependent loop-growth hypothesis, kept as a curve just as $b_{ST}(\omega)$ is. A three-bin moving median is applied across adjacent frequency bins:

\[b_{res}(\omega)=\operatorname{median}_3 \left\{b\!\left(\alpha\rho(\omega)L_0(\omega)\right)\right\},\qquad\omega\in\Omega\] $\operatorname{median}_3$ means three adjacent frequency bins, not three time windows.

SECTION 06 / 08

Per-Frequency Fusion of Stability Evidence

Neither branch is trusted everywhere. Both are kept as curves over frequency, every bin is charged for the evidence it actually has, and only then does the weakest bin govern.

The 0.5 s command RMS defines the binary activity $A$ directly. The approved threshold is $\eta_A=0.0575$, approximately $4.54\sigma_{\mathrm{noise},u}$ based on the clean quiet-record estimate:

\[A=\begin{cases} 1,&\operatorname{RMS}_{0.5\,\mathrm{s}}(u)>\eta_A\\[6pt] 0,&\text{otherwise} \end{cases}\] \[\eta_A=0.0575\approx4.54\sigma_{\mathrm{noise},u}\]

Activity is no longer a regime switch that selects one scalar margin or the other. It enters only where it belongs: inside the confidence $c(\omega)$ of the identification branch, and in the fast drive-ratio detector of the residual branch.

Why the fusion is per frequencyA chordal margin is defined at a frequency, and the loop margin is the weakest of them. Collapsing each branch with $\min_\omega$ first and then combining the two scalars mixes margins taken at different frequencies, which is not a quantity with a meaning. The minimum therefore runs last, after each bin has formed its own estimate.

Two independent kinds of evidence exist at every bin, and each one has to pay for the claim it makes. The first is the confidence $c(\omega)$ already built in Section 03: command energy and coherence say the loop is directly visible at this frequency, so the identified margin $b_{ST}(\omega)$ is worth believing.

\[w_{ST}(\omega)=c(\omega)=A\,\gamma^2(\omega)\,\ell(\omega)\]

The second is a detection weight $d(\omega)$. The fitted loop growth $\rho(\omega)$ only means something once it clears the resolution of the $\rho$ fit itself; below the threshold $\rho_{det}=1.50$ the deviation is fit noise. Where $\rho$ does clear it, the residual model $b_{res}(\omega)$ is worth believing to the extent the loop is not directly visible:

\[d(\omega)=\operatorname{clamp}\!\left(\frac{\rho(\omega)-1}{\rho_{det}-1},0,1\right), \qquad \rho_{det}=1.50\] \[w_{res}(\omega)=\big(1-c(\omega)\big)\,d(\omega)\]

The two weights never sum to more than one. Whatever is left over is the bin's admission that it has no evidence at all, and a bin with no evidence makes no claim: it reports the ceiling $1/\sqrt2$, which cannot drag a minimum downward.

\[b(\omega)=w_{ST}(\omega)\,b_{ST}(\omega) +w_{res}(\omega)\,b_{res}(\omega) +\big(1-w_{ST}(\omega)-w_{res}(\omega)\big)\frac{1}{\sqrt2}\] \[b_{raw}[n]=\min_{\omega\in\Omega}b(\omega)\] Weight, weight, worst-of. The $\min$ now acts on a per-frequency estimate rather than on two pre-collapsed scalars.

The factor $\sigma_b$ smooths the reported margin over time exactly as before:

\[b[n]=b[n-1]+\sigma_b\big(b_{raw}[n]-b[n-1]\big)\]

The quiet case stops being a special case

When nothing drives the loop, $A=0$, so $c(\omega)=0$ at every bin and $w_{ST}$ vanishes identically. What remains is decided by $d(\omega)$ alone:

Quiet, loop unchanged

$\rho\approx1$, so $d=0$ and $w_{res}=0$. Every bin reports $1/\sqrt2$: the estimator has observed nothing and asks for no change in adaptive gain.

Quiet, damage remembered

$\rho>\rho_{det}$, so $d=1$ and the bin keeps reporting $b_{res}(\omega)$ — the remembered loop — until the recovery criterion forgets it.

No separate idle margin, no activity cross-fade, and no memory latch is needed to produce this behaviour; it falls out of the same expression that handles the excited case.

An unsupported bin must report the ceiling, not the priorWeighting the two branches by $c$ and $1-c$ alone fails, and the failure is instructive: $\min_\omega$ self-selects the bins where $c\approx0$, because those are exactly the ones such a blend leaves lowest. The identification branch then never governs and the reading becomes the noise of the $\rho$ fit at unexcited frequencies. Measured on the live scenario, $b$ tracked $b_{res}$ to three decimals while $b_{ST}$ sat about 0.25 higher and unused. Charging each branch for its own evidence is what removes the pathology.

Recovery

Only the residual branch carries memory, so it is the only thing that has to forget. That memory exists because the observed output power stood above the healthy reference, so it decays whenever that is no longer true — one criterion covering both the quiet case and the driven-after-repair case:

\[\log\rho[n]\;\longleftarrow\;\log\rho[n]\Big(1-\sigma_{rec}\,\mathbb 1\{r_{\mathcal Q}<1\}\Big), \qquad \tau_{rec}=2\,\mathrm{s}\] $r_{\mathcal Q}$ is the quiet-set reference ratio from Section 05.

This replaces both the blind decay that ran only while $A=0$ and the two-threshold release/re-engage hysteresis on $r_{\mathcal Q}$.

Separation of Stability Estimation and Adaptive-Gain Control

OSI estimates the stability margin $b$, while a separate adaptive-gain law determines the controller response.

Important separationThe estimator does not directly choose PID gains. It receives the currently applied adaptive factor $\alpha$ (stored as a_cmd), evaluates the corresponding loop, and returns evidence for a separate adaptive-gain controller.

The adaptive factor uniformly scales the inner open loop:

\[L(j\omega,\alpha,k)=\alpha L(j\omega,1,k)\]

Because a positive scale changes magnitude but not phase, the $-180^\circ$ crossover frequency stays approximately fixed. The gain margin changes in closed form:

\[GM_{dB}(\alpha,k)=GM_{dB}(1,k)-20\log_{10}(\alpha)\]

Let $GM_{target}$ be the desired gain margin. The scale required to meet that target is $\alpha_{required}(k)$:

\[\alpha_{required}(k)=10^{\left(GM_{dB}(1,k)-GM_{target}\right)/20}\]

The adaptive law keeps $\alpha$ between the permitted minimum $\alpha_{min}$ and 1. When damage raises loop gain and $b$ falls, reducing $\alpha$ can restore separation from the critical condition. Recovery should be slower and evidence-based so one optimistic window cannot rush the adaptive factor upward.

Integrated Mathematical Formulation of the OSI Estimator

The complete OSI update is summarized as an eight-stage computational sequence.

01What moved?Append $u,y$ and measure command activity.
02At which frequencies?Window, FFT, and smooth $\Phi_{uu},\Phi_{yy},\Phi_{yu}$.
03Is the ratio believable?Combine activity, coherence, and leverage into confidence.
04What loop produced it?Blend $\widehat T$ with $T_{prior}$, then invert to $\widehat L$.
05How close is critical?Evaluate the chordal curve and take its minimum.
06What if input is quiet?Fit $\rho$ from output power relative to a fixed healthy reference.
07What can each bin support?Weight $b_{ST}(\omega)$ by $c$, $b_{res}(\omega)$ by $(1-c)d$, the rest claims nothing; take the worst bin.
08What should be reported?Smooth and clamp $b\in[0,1/\sqrt2]$; pass it to the adaptive-gain law.
\[\boxed{\;(u,y,L_0,\alpha)\;\longrightarrow\;\widehat L\;\text{and}\;\rho\;\longrightarrow\;b_{ST}(\omega),b_{res}(\omega)\;\longrightarrow\;\min_{\omega\in\Omega}b(\omega)\;\longrightarrow\;b\;}\]

Correspondence Between Mathematical Formulation and Implementation

Read makeConfig as the mathematical constants, makeState as estimator memory, and stepEstimator as the eight-stage pipeline above. This formulation corresponds to research/sol_osi_simplified_5/sol_osi_simplified_5.m; it does not replace the production SOL-OSI implementation.

Relative to research/sol_osi_simplified, the fusion of Section 06 removes the memory gain of 21.75, the two-threshold release/re-engage latch, the separate idle margin and the activity cross-fade — three tunable parameters and one latched state, replaced by $\rho_{det}$ and a single recovery constant. On the Fabby Benchmark it passes all seven gates with a composite of 75.0 against 73.6 for the earlier form.
