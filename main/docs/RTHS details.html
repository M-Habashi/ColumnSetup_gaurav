RTHS Details

Reference definitions for the real-time hybrid simulation error indicators currently implemented in the MATLAB code.

Signals Indicators Code sources

Signal Pairing

The indicators use two different references. Tracking indicators compare measured displacement to the replayed numerical control point. Reference indicators compare replayed floors or measured displacement to the full FEM reference.

Units in the code
  • dm, replayed numerical control point, and full FEM control point are compared in millimeters.
  • Floor responses are compared in meters.
  • J1 is reported in milliseconds. J2 through J7 are reported in percent.

Error Indicators

Indicator Code definition Unit
J1 Delay between measured dm and the replayed numerical control point from cross-correlation. ms
J2 Normalized RMS/std error between measured dm and the replayed numerical control point.

100 * std(dm - dd_replay) / std(dd_replay)

 %
J3 Peak absolute error between measured dm and the replayed numerical control point.

100 * max(abs(dm - dd_replay)) / max(abs(dd_replay))

 %
J4 First-floor replayed numerical response versus the first-floor full FEM reference.

100 * std(u_num_1 - u_ref_1) / std(u_ref_1)

 %
J5 Second-floor replayed numerical response versus the second-floor full FEM reference.

100 * std(u_num_2 - u_ref_2) / std(u_ref_2)

 %
J6 Third-floor replayed numerical response versus the third-floor full FEM reference.

100 * std(u_num_3 - u_ref_3) / std(u_ref_3)

 %
J7 Normalized mean square error of measured dm against the full FEM control-point reference.

100 * mean((dm - u_control_ref)^2) / mean(u_control_ref^2)
