FEM idealization

FEM 3 calibration

The saved model is fem_sp_1_org_3.mat with variant inner_column_base_rotation_double_w12x40. The calibrated exterior base rotational stiffness is 1.19410864e7 N·m/rad; the two interior column bases use twice that stiffness.

Rigid floor diaphragms

All nodes at a given floor share one horizontal displacement. Every beam-column and base joint has a rotational degree of freedom. Rotations at different joints remain independent during assembly and are then statically condensed, leaving three lateral generalized coordinates: u₁, u₂, and u₃.

Base rotational springs

Each numerical column base is represented as a translationally restrained hinge with rotational coordinate θb connected to the calibrated spring kθ. The spring supplies moment Mb = kθθb while permitting finite base rotation.

Dynamic model

Use a three-DOF lateral system with the corresponding level mass lumped at each diaphragm. Levels 1–2 use the full floor live load in the stated earthquake combination; the roof uses 0.5 of the floor live load. Weight values are derived only for gravity-load reporting. Apply 3% damping (ζ = 0.03) to the selected modes and evaluate both signs of the earthquake action, ±E.

Coupling concept

The numerical FEM retains the interface horizontal translation uI explicitly and removes the lower 1.016 m left exterior column segment. The experiment is represented only by its measured lateral stiffness k in N/m and returns Fexp = kuI in N at that interface coordinate. A numerical roller supplies the vertical reaction, so the experiment receives no axial load; the released interface also transfers no experimental moment. The factor of two in FEM 3 applies only to the two interior-column base rotational springs.

SI modeling basis: geometry in m, force in N, mass in kg, stiffness in N/m, and damping in N·s/m.
